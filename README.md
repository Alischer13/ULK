# ULK
This project contain R scripts for transcriptomic analyses and to generate figures

All R scripts to generate figures are located in R_scripts

### Project consist of two parts, strucure as follows:
1. Transcriptomic analyses of transmembrane protein producers
   - Data in data/
   - Metadata in data/meta/
   - Results in results/
2. Transcriptomic analyses of previouly generated transcriptomic data in CriptoFc directory
   - Data in CriptoFc/data/
   - Metadata in CriptoFc/data/meta/
   - Results in CriptoFc/results/
