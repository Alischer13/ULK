kallisto_ULK.sh
- Ran on Uppmax
- Inputs:
	- raw reads (../data/fastq/)
	- Reference Homo_sapiens.GRCh38.cdna.all.fa.gz (or indexed) 
	- Metadata table, with file names (../meta/metadata.txt)
1. Generates kallisto index from ref (unless it exists)
2. Trim galore -> generates trimmed reads (../data/trimmed/)
3. Pseudoaligns with kallisto (../data/kallisto_out/)
